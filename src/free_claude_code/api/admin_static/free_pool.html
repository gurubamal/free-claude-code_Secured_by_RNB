Paid access and priority

Uses the connected account's allowance or purchased credits. A successful login does not guarantee a 512k+ model.

Requests can incur provider charges. Set spending limits with each provider; this gateway has no monetary budget cap. These switches do not purchase credits or bypass account limits.

Move providers up or down to choose priority within each billing category. Uncheck a provider to exclude it. Within each category, try providers in order before their sibling models. Each request considers up to 12 candidates, reserving a slot for every eligible billing category.
